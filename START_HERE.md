# Start here

1. Read [the project overview and installation](README.md) or [中文说明](README.zh-CN.md).
2. Inspect [measured results](docs/RESULTS.md) and [their scope](docs/METHODOLOGY.md).
3. Follow [the reproducibility guide](docs/REPRODUCING.md) for a new local run.

The public `reports/` directory contains sanitized evidence from the recorded research runs. New execution writes to ignored `results/` and uses externally obtained model/data assets.
